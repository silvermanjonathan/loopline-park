Chunks explored
Chunk 1 · The prize wheel

random.choice() — the spin

The Prize Wheel booth picks from a list — but not the way an index does. random.choice() lets chance pick the spot.

import random

prizes = ["plush comet", "giant lollipop", "glow bracelet", "free ride pass"]
print(random.choice(prizes))
Predict Run this program five times in a row. Will you get the same prize all five times? Why or why not?
Almost certainly not — each run is a fresh spin, and any of the four prizes can come up (repeats are allowed; chance has no memory). That's the difference from prizes[2], which picks the same spot every single time.
You should see 
glow bracelet
...or any other prize — and different answers across your five runs.
Chunk 2 · What comes off the wheelE5-PRO-VD-?? ⚠

An item, not a number

import random

prizes = ["plush comet", "giant lollipop", "glow bracelet", "free ride pass"]
winner = random.choice(prizes)
print("You won: " + winner)
Predict What does random.choice() hand back and store in winner — the prize itself, or the index number of the prize?
The prize itself — the actual string, like "glow bracelet", never a number like 2. That's why line 5 can glue it straight into the message. It picks straight off the shelf and hands you the item.

You won: free ride pass
(with the prize varying run to run)
Chunk 3 · Spot the copiesE5-PRO-RD-?? ⚠

Read this blueprint like an inspector

An engineer left this in the studio — three triangle supports for a sign. Read it before you run it.

import turtle
t = turtle.Turtle()

for side in range(3):
    t.forward(60)
    t.right(120)
t.penup()
t.forward(90)
t.pendown()

for side in range(3):
    t.forward(60)
    t.right(120)
t.penup()
t.forward(90)
t.pendown()

for side in range(3):
    t.forward(60)
    t.right(120)

turtle.done()
Predict Which lines are exact copies of each other, and how many times does the copy appear? (penup() lifts the pen so a move draws nothing; pendown() puts it back.)
The three-line triangle block — for side in range(3): + forward(60) + right(120) — appears three times, pasted word for word, with a pen-up hop between copies. A loop can't fix this one (the hop sits between the shapes), and copy-paste is how bugs breed: fix one copy, forget the others. What this blueprint needs is a name for the repeated block. That's Chunk 4.
You should see Three triangles in a row, with gaps between them.
Chunk 4 · def — the blueprint stampE5-PRO-PD-?? ⚠

Name the block... and hit run

def carves a block of code and gives it a name — a rubber stamp for the studio. Here's the triangle, stamped:

import turtle
t = turtle.Turtle()

def draw_support():
    for side in range(3):
        t.forward(60)
        t.right(120)

turtle.done()
Predict — this is the day's big trap The triangle code is right there, correctly written. When you run this program, what gets drawn?
Nothing. Total silence. The window opens, empty. def only makes the stamp — it never presses it onto the page. Defining is not calling. Sit with that empty window for a second; half the room will hit this exact silence today and think their program broke. It didn't. It's waiting to be asked.
Chunk 5 · The callE5-PRO-PD-?? ⚠

Press the stamp

To use the stamp, write its name with parentheses. Once per press:

def draw_support():
    for side in range(3):
        t.forward(60)
        t.right(120)

draw_support()
t.penup()
t.forward(90)
t.pendown()
draw_support()
Predict How many triangles get drawn — and which lines make that happen?
Two — one per call. The two draw_support() lines are the presses. Two steps, always: make the stamp (def), then press it (call). Compare with Chunk 3: eighteen pasted lines have become one stamp used twice — and if the triangle ever needs fixing, you fix it in exactly one place.
You should see Two triangles with a gap between them.
Chunk 6 · ParametersE5-PRO-RD-?? ⚠

One stamp, any wheel — spokes

A parameter is a blank on the stamp. Fill the blank with a different number at each call, and one function draws endless different wheels. Here's yesterday's Ferris wheel, stamped with a spokes blank:

import turtle
t = turtle.Turtle()
t.speed(0)

def draw_wheel(spokes):
    for spoke in range(spokes):
        t.forward(80)
        t.backward(80)
        t.right(360 / spokes)

draw_wheel(6)

turtle.done()
Predict draw_wheel(6) fills the blank with 6. How many spokes appear, and what angle sits between them? What would draw_wheel(12) draw instead?
Six spokes, 60° apart (360 ÷ 6) — and draw_wheel(12) gives twelve spokes 30° apart, from the same unchanged function. The number you pass lands in the spokes blank, and Day 2's angle rule does the rest. One stamp, any wheel.
You should see A six-spoke wheel: the turtle walks out, walks back, turns, repeats.
Chunk 7 · A second blank

spokes and size

Stamps can have more than one blank. Order matters — the first number fills the first blank, the second fills the second:

def draw_wheel(spokes, size):
    for spoke in range(spokes):
        t.forward(size)
        t.backward(size)
        t.right(360 / spokes)

draw_wheel(8, 100)
draw_wheel(12, 50)
Predict Describe the two wheels these calls draw. Which one is bigger? Which has more spokes?
First: 8 long spokes (length 100). Second, drawn on top: 12 short spokes (length 50) — more spokes, smaller wheel. It's the position of each number that decides which blank it fills, not any magic in the names.
You should see A big 8-spoke wheel with a small dense 12-spoke wheel layered at its center.
Hinge question · stop here until you're sureE5-PRO-PD-?? ⚠

The two steps

What are the two steps to using a function — and what happens if you only do the first one?

Define it, then call it. Define-only means silence: the stamp exists but never touches the page, the program runs, and nothing appears. If you answered "write it and run it," go back to Chunk 4 and feel the empty window again before the build.
Build brief · One stamp, three wheels

Regenerate Tuesday's art with three calls

Using draw_wheel(spokes, size), produce a piece of Ferris-wheel art made of three different wheels — three calls, different numbers each time. Use penup() / goto(x, y) / pendown() to move between wheels without drawing.

Useful pieces: def · parameters · t.penup() · t.goto(-150, 0) · t.pendown() · t.color().

Suggested start: get one call working. Then add the pen-up hop and a second call. Three is just one more hop.

import turtle
t = turtle.Turtle()
t.speed(0)

def draw_wheel(spokes, size):
    for spoke in range(spokes):
        t.forward(size)
        t.backward(size)
        t.right(360 / spokes)

t.penup()
t.goto(-180, 0)
t.pendown()
draw_wheel(6, 60)

t.penup()
t.goto(0, 0)
t.pendown()
draw_wheel(10, 80)

t.penup()
t.goto(180, 0)
t.pendown()
draw_wheel(16, 50)

turtle.done()
Count the line savings: without the stamp, this picture is three pasted copies of the wheel code. At the Test Ride, show your three wheels and name what each number in each call controlled.

Choose your exit gate

Floor · approaching the standard

Your prize wheel runs on a prize list you wrote, and you can define draw_wheel() and call it once — and explain the silence when the call is missing.

Middle · meets the standard

One draw_wheel(spokes, size) function, three calls, three visibly different wheels — and you can say which number controls what.

Stretch · exceeds the standard

Let chance design the ride: draw_wheel(random.choice([6, 8, 12, 20]), 80) — a surprise wheel every run. Then explain to a partner how today's two ideas just teamed up.
