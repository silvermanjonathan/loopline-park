Chunks explored
Chunk 1 · Questions with two answers

True or False — nothing in between

A comparison is a question the computer answers with exactly True or False. Read > aloud as a question: "is height more than 48?"

height = 52
print(height > 48)
print(height > 60)
Predict What two words print? (Not numbers — words.)
True, then False. 52 is more than 48, and not more than 60. These two values are called booleans, and they're the fuel every decision runs on.

Chunk 2 · The safety gateE5-ALG-PS-01

if / else — the gate decides

The Comet requires 48 inches. The gate checks and picks one path:

height = int(input("Your height in inches? "))

if height >= 48:
    print("Gate open — enjoy The Comet!")
else:
    print("Not this ride today — Splash Canyon awaits!")
Predict A guest types 45. Both messages are right there in the code — do both print, or one? Which?
Only one: Not this ride today — Splash Canyon awaits! The condition height >= 48 is False for 45, so Python skips the if block and runs the else block. Code being visible doesn't make it run — the condition is the switch. (>= means "48 or more," so a guest who is exactly 48 gets in.)

Your height in inches? 45
Not this ride today — Splash Canyon awaits!
Run it three times: once under 48, once over, once exactly 48.
Chunk 3 · Three-way forkE5-ALG-PS-01

elif — child, family, or thrill

The park has three ride bands. elif ("else if") adds a middle path. Python checks top to bottom and takes the first true path — then skips the rest.

height = int(input("Your height in inches? "))

if height < 36:
    print("Child rides — the Tea Cups are calling!")
elif height < 48:
    print("Family rides — all aboard Splash Canyon!")
else:
    print("Thrill rides — The Comet and Sky Drop!")
Predict A guest types 40. Walk the fork: is 40 < 36? Is 40 < 48? Which single message prints?
Family rides — all aboard Splash Canyon! First check: 40 < 36 is False, move on. Second check: 40 < 48 is True — take this path and skip everything after it. An elif chain is a fork in the queue: one guest, one path, every time.
You should see Exactly one band message per run. Test all three bands: try 30, 40, and 55.
Chunk 4 · The lookalike bug

= assigns. == asks.

Two symbols, nearly identical, totally different jobs. One = puts a value in a box ("gets"). Double == asks a question ("is it the same?"). Watch what happens when they're swapped:

secret_code = 7

if secret_code = 7:
    print("Staff door open")
Predict Line 3 uses a single = inside the if. Will this run and print, run and stay silent, or refuse to run at all?
It refuses to run — a SyntaxError before anything happens. Python won't let you put an assignment where a question belongs. The fix is if secret_code == 7:. Say every condition aloud as a question — "is secret_code the same as 7?" — and your hands will type the right symbol.
Chunk 5 · ListsE5-PRO-VD-?? ⚠

The ride roster — one shelf, many rides

One variable can hold a whole list. Each item has a numbered spot called its index — and the first spot is 0, not 1. (Yes, really. Let the discomfort sit for a second.)

rides = ["The Comet", "Splash Canyon", "Tea Cups", "Sky Drop"]

print(rides[0])
print(rides[2])
Predict Which two ride names print? Careful — count spots starting from 0.
The Comet (index 0 — the first spot) and Tea Cups (index 2 — the third spot). The list is the shelf; the index picks the ride. And what's at index 4? Nothing — asking for rides[4] crashes with an IndexError, because the four spots are numbered 0, 1, 2, 3.

Chunk 6 · Loop the shelfE5-PRO-VD-?? ⚠

Print the park map

A for loop can visit every item on the shelf, in order, without you naming any index. len() tells you how many items the shelf holds.

rides = ["The Comet", "Splash Canyon", "Tea Cups", "Sky Drop"]

print("LOOPLINE PARK — TODAY'S RIDES")
for ride in rides:
    print("- " + ride)

print(len(rides))
Predict How many ride lines print? What number does len(rides) give — and is that the same as the last index?
Four ride lines, and len(rides) is 4 — but the last index is 3. Count of items and last spot number are always one apart, because counting starts at 0. That gap is where almost every list bug in the world lives: last index = len() minus one.

Chunk 7 · The prize wheelE5-PRO-VD-?? ⚠

random.choice() — chance picks off the shelf

The midway's Prize Wheel picks from a list — but not the way an index does. random.choice() lets chance pick the spot. The toolbox is random; the drawer is choice.

import random

prizes = ["plush comet", "giant lollipop", "glow bracelet", "free ride pass"]
winner = random.choice(prizes)
print("You won: " + winner)
Predict Run it five times in a row. Same prize all five? And what lands in winner — the prize itself, or its index number?
Almost certainly not the same — every run is a fresh spin, repeats allowed, chance has no memory. And winner holds the item itself — the actual string, like "glow bracelet", never a number like 2 — which is why line 5 can glue it straight into the message. Compare with prizes[2]: the index picks the same spot every single time. Chance and index — two different hands reaching for the same shelf.

Chunk 8 · def — the blueprint stampE5-PRO-PD-?? ⚠

Name the block… and sit with the silence

An engineer needed three triangle supports for a sign and pasted the same block three times — and copy-paste is how bugs breed: fix one copy, forget the others. def carves a block of code and gives it a name — a rubber stamp for the studio. New file, type this, run it:

import turtle
t = turtle.Turtle()

def draw_support():
    for side in range(3):
        t.forward(60)
        t.right(120)

turtle.done()
Predict — this is the day's big trap The triangle code is right there, correctly written. When you run this, what gets drawn?

Nothing. Total silence. The window opens, empty. def only makes the stamp — it never presses it onto the page. Defining is not calling. Sit with that empty window for a second; you will meet this exact species of silence again tomorrow, and you'll be the one who knows what it means.

To use the stamp, write its name with parentheses — once per press. Add this below the def block, above turtle.done():

draw_support()
t.penup()
t.forward(90)
t.pendown()
draw_support()

Two triangles — one per call, with a pen-up hop between them. Two steps, always: make the stamp (def), then press it (call). And the triangle now lives in exactly one place: fix it once, every press is fixed.

You should see An empty window on the first run — then, after adding the calls, two triangles with a gap between them.
Chunk 9 · ParametersE5-PRO-PD-?? ⚠

One stamp, any wheel

A parameter is a blank on the stamp. Fill the blank with a different number at each call, and one function draws endless different wheels:

import turtle
t = turtle.Turtle()
t.speed(0)

def draw_wheel(spokes):
    for spoke in range(spokes):
        t.forward(80)
        t.backward(80)
        t.right(360 / spokes)

draw_wheel(6)

turtle.done()
Predict draw_wheel(6) fills the blank with 6. How many spokes appear, and what angle sits between them? What would draw_wheel(12) draw instead?
Six spokes, 60° apart (360 ÷ 6) — and draw_wheel(12) gives twelve spokes 30° apart, from the same unchanged function. The number you pass lands in the spokes blank, and Monday's angle rule does the rest. Stamps can hold two blanks — def draw_wheel(spokes, size): — and it is the position of each number that decides which blank it fills: draw_wheel(8, 100) then draw_wheel(12, 50) layers a small dense wheel inside a big sparse one. One stamp, any wheel.
You should see A six-spoke wheel: the turtle walks out, walks back, turns, repeats.
Chunk 10 · The other listE5-PRO-VD-?? ⚠

Coaster preview — a list that holds a roller coaster

Everything you just did with ride names works on numbers — and tomorrow, one list of numbers becomes the roller coaster that opens at Friday's Grand Opening. Each number is a support tower's height in meters, left to right. Same shelf, higher stakes.

track = [50, 48, 42, 33, 22, 11, 2, 0, 8, 18, 26, 30, 26, 18, 9, 3, 0]

print(len(track))
print(track[0])
print(track[7])
Predict Three numbers print: one is a count of towers, two are heights in meters. Which three? And the trap from Chunk 7 is lurking: what's the last tower's index?
17, then 50, then 0. track[0] is the first tower — the 50 m lift hill. track[7] is the eighth: ground level, the bottom of the big drop. And with 17 towers, the last one is track[16] — count and last spot, one apart, exactly Chunk 7's gap. On a name roster, getting that wrong prints the wrong ride. On this week's coaster, it crashes a real one.

Build brief · The Park Map, Gate & Prize

Roster + map + gate + one lucky spin

Build a program that:

1. Stores at least 4 rides you invent in a list.
2. Prints the park map by looping over the roster.
3. Asks the guest's height and runs a three-band gate (if / elif / else) recommending a ride from your roster.
4. Ends with a prize spin: random.choice() on a prize list you invent.

Useful pieces: [ ] lists · for ... in ... · len() · int(input()) · if / elif / else · < and >= · random.choice().

Suggested start: get the map printing first. The gate is today's Chunk 3 with your own ride names dropped in.

rides = ["The Comet", "Splash Canyon", "Tea Cups", "Sky Drop"]

print("LOOPLINE PARK — TODAY'S RIDES")
for ride in rides:
    print("- " + ride)

height = int(input("Your height in inches? "))
if height < 36:
    print("We recommend: " + rides[2])
elif height < 48:
    print("We recommend: " + rides[1])
else:
    print("We recommend: " + rides[0])
Then the spin, at the bottom: 
import random
prizes = ["plush comet", "sticker sheet", "glow bracelet"]
print("Lucky spin! You won: " + random.choice(prizes))
Notice the gate picks rides by index — the decision and the shelf working together — while the prize comes off its shelf by chance.
3:25 · Test Ride — Tomorrow's engine, two experiments

The physics arrives tonight

Tomorrow you assemble a roller coaster. Its whole engine rests on two ideas, and both fit in a scratch file. Class Cards 02 and 03 are the paper versions of these exact experiments.

Experiment A — the speed of falling. drop is how far a coaster has fallen below its lift hill; math.sqrt lives in the math toolbox — today's pattern again: toolbox, then drawer. :.0f is Monday's rounding dial and 2.24 converts to mph.

import math

GRAVITY = 9.8

drop = 20
speed = math.sqrt(2 * GRAVITY * drop)
print(f"{speed * 2.24:.0f} mph")
Predict — this one surprises almost everyone drop = 20 prints 44 mph. Change it to 40 — exactly double the fall. Does the speed double to 88? Commit, run — then try 80, then 99: the real height of Fury 325, the tallest chain-lift coaster on Earth, which tops out at 95 mph.
63, not 88 — then 89, then 99. Every doubling of the drop multiplies the speed by about 1.4: that is what a square root does to a doubling. To truly double a coaster's speed you need four times the drop, which is why nobody builds them that way. And your one line predicts Fury 325 just 4 mph hot — the missing speed is friction and air, which this line doesn't charge… yet.

Experiment B — the engine with no wheels. The move line, read the Monday way: “position gets its old self, plus one step.” The real engine takes 60 tiny steps a second; here we take one big 1-second step so you can watch each one land.

import math

GRAVITY = 9.8
top = 50

position = 0.0
speed = 2.0

for step in range(14):
    height = 50 - position / 4        # a dead-straight 200-meter ramp
    drop = top - height
    speed = math.sqrt(2 * GRAVITY * drop)
    if speed < 2:
        speed = 2                     # the chain's shove
    position = position + speed * 1.0     # one big 1-second step
    print(f"after {step + 1} s:  position {position:.1f} m   speed {speed * 2.24:.0f} mph")
Predict — commit before you run Steps 1 and 2 move the train about 2 and 3 meters. Nothing in this loop says “speed up.” Step 10: still about 3 meters — or more? Why?

Step 10 covers about 20 meters, and every step beats the last: 2, 3, 5, 7, 9… Each pass, the train sits lower, so drop grows, so the sqrt line hands the move line a bigger speed, so the step grows. The rushing emerges from two lines cooperating — a rule deciding what happens next, not a script saying where to be.

Last move of the day: delete the two chain's-shove lines and rerun. Fourteen identical lines — position 0.0 m speed 0 mph — forever, silently, with no error. Today's stamp silence, wearing physics. Remember it: tomorrow you will see it on a real screen, and you'll already know the cure.
