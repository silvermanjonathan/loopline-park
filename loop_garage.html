Loop-de-Loops

Your Day 3 engine + five green zones = upside down. See exactly where they go, turn two dials, make it yours.

YOU'LL NEED: your working coaster.py from Day 3 · pygame (turtle riders: pair up with a pygame machine for this one) · your Ride Log

How this page works

For the RUNNING lane: your Day-3 ride completes and you want it upside down. Below is your engine with the loop code highlighted green exactly where it lives — five zones, numbered in the comments. White lines are your engine, untouched. Copy your working file into a comment, then paste the whole thing.

The one rule (it decides every loop you'll ever place): the drop above the loop's base must be at least 2½ × the radius. Your budget = (lift height − base height) ÷ 2.5. Overspend and the train lets go at the top.
The map · your engine + the five green zones

Where the loop code goes

Zone 1: the two dials. Zone 2: where the circle sits on screen. Zone 3: two single lines (more rail, a new flag). Zone 4: before the physics — it tells height the truth about the circle, and the physics eats height. Zone 5: the inspector, plus the drawing. Notice what's not green: the drop line, the square root, the move line. The loop never touches them.

# ==========================================================
#  LOOPLINE PARK - COASTER SIMULATOR  (loop edition)
#  Your Day 3 engine + one vertical loop, in 5 numbered zones.
# ==========================================================

import pygame
import math

# --- YOUR TRACK -------------------------------------------
# Each number is a hill height in meters, left to right.
# Rule 1: the FIRST number is the lift hill. It must be the tallest.
# Rule 2: change these numbers and rerun. That IS the design job.

track = [50, 48, 42, 33, 22, 11, 2, 0, 8, 18, 26, 30, 26, 18, 9, 3, 0]

SEG_LEN = 20          # each hill tower sits 20 meters from the next

# === LOOP ZONE 1 of 5: the dials ==========================
LOOP_AT = 120.0       # meters along the track (tower 6 = 6 x 20, the valley)
LOOP_R = 8.0          # loop radius in meters
LOOP_LEN = 2 * 3.14159 * LOOP_R      # extra rail the loop adds (~50 m)

GRAVITY = 9.8
FPS = 60
DT = 1.0 / FPS        # how much time passes in one frame

# --- COLORS (Loopline Park) -------------------------------
NAVY = (27, 41, 81)
YELLOW = (252, 211, 77)
RED = (220, 38, 38)
CREAM = (248, 250, 252)
GREEN = (16, 185, 129)

# --- SETUP ------------------------------------------------
pygame.init()
screen = pygame.display.set_mode((900, 600))
pygame.display.set_caption("Loopline Park - Coaster Simulator")
clock = pygame.time.Clock()
big = pygame.font.SysFont("couriernew", 30, bold=True)
small = pygame.font.SysFont("couriernew", 18)

# --- TURNING A HILL HEIGHT INTO A SCREEN SPOT -------------
tallest = max(track)
step_x = 800 / (len(track) - 1)
scale_y = 400 / tallest

rail_points = []
for i in range(len(track)):
    x = 50 + i * step_x
    y = 550 - track[i] * scale_y
    rail_points.append((x, y))

# === LOOP ZONE 2 of 5: where the circle sits on screen ====
loop_seg = int(LOOP_AT / SEG_LEN)
if loop_seg > len(track) - 2:
    loop_seg = len(track) - 2        # same guard the engine uses
loop_frac = (LOOP_AT - loop_seg * SEG_LEN) / SEG_LEN
loop_base = track[loop_seg] + (track[loop_seg + 1] - track[loop_seg]) * loop_frac
loop_cx = 50 + (LOOP_AT / SEG_LEN) * step_x
loop_cy = 550 - (loop_base + LOOP_R) * scale_y
loop_rpx = LOOP_R * scale_y

# --- RUN THE RIDE -----------------------------------------
top = track[0]
position = 0.0                       # how many meters along the track we are
track_length = (len(track) - 1) * SEG_LEN + LOOP_LEN   # ZONE 3a: the loop adds rail
speed = 2.0
stalled = 0
fell = 0                             # ZONE 3b: the new failure flag

for frame in range(3000):
    pygame.event.pump()              # keeps the window alive

    # === LOOP ZONE 4 of 5: are we on the loop? =============
    # (must run BEFORE the physics - the physics eats height)
    on_loop = (position >= LOOP_AT) and (position < LOOP_AT + LOOP_LEN)
    if on_loop:
        flat = LOOP_AT                       # the loop stands still on the map
        angle = (position - LOOP_AT) / LOOP_R    # how far around the circle
    else:
        flat = position
        if position >= LOOP_AT + LOOP_LEN:
            flat = position - LOOP_LEN       # past the loop: subtract its rail
        angle = 0.0

    # WHERE ARE WE? -- find the two towers we are between
    seg = int(flat / SEG_LEN)
    if seg > len(track) - 2:
        seg = len(track) - 2
    frac = (flat - seg * SEG_LEN) / SEG_LEN

    # our height is part way between those two towers
    height = track[seg] + (track[seg + 1] - track[seg]) * frac
    if on_loop:
        height = height + LOOP_R * (1 - math.cos(angle))   # tell height the truth

    # THE PHYSICS: height you have lost becomes speed you have gained
    drop = top - height
    if drop < 0:
        stalled = 1
    else:
        speed = math.sqrt(2 * GRAVITY * drop)
        if speed < 2:
            speed = 2                # the chain lift lets go at 2 m/s

    # === LOOP ZONE 5 of 5: the loop inspector ==============
    # upside down, speed is the only thing holding the rail
    if on_loop and angle > 1.57 and angle < 4.71:
        if speed * speed < GRAVITY * LOOP_R:
            fell = 1

    # move forward by however fast we are going
    if stalled == 0 and fell == 0:
        position = position + speed * DT

    # --- DRAW -------------------------------------------------
    screen.fill(NAVY)
    pygame.draw.line(screen, GREEN, (50, 550), (850, 550), 3)
    pygame.draw.lines(screen, YELLOW, False, rail_points, 4)

    # support towers under each hill
    for i in range(len(track)):
        pygame.draw.line(screen, (60, 80, 130),
                         (rail_points[i][0], rail_points[i][1]),
                         (rail_points[i][0], 550), 2)

    # the loop (drawn every frame, before the train)
    pygame.draw.circle(screen, YELLOW, (int(loop_cx), int(loop_cy)), int(loop_rpx), 4)

    # the train (rides the circle while on the loop)
    if on_loop:
        tx = loop_cx + loop_rpx * math.sin(angle)
        ty = loop_cy + loop_rpx * math.cos(angle)
    else:
        tx = 50 + (flat / SEG_LEN) * step_x
        ty = 550 - height * scale_y
    pygame.draw.rect(screen, RED, (tx - 16, ty - 14, 32, 14), border_radius=4)

    # the dashboard
    screen.blit(big.render(f"SPEED  {speed * 2.24:.0f} mph", True, CREAM), (50, 30))
    screen.blit(small.render(f"HEIGHT {height:.0f} m", True, CREAM), (50, 70))
    screen.blit(small.render(f"TIME   {frame * DT:.1f} s", True, CREAM), (50, 92))

    if stalled == 1:
        screen.blit(big.render("STALLED - hill taller than the lift!", True, RED), (50, 500))
    if fell == 1:
        screen.blit(big.render("TOO SLOW AT THE TOP - the train let go!", True, RED), (50, 500))

    pygame.display.flip()
    clock.tick(FPS)

    if position >= track_length:
        break

pygame.time.wait(3000)
pygame.quit()
You should see A yellow circle in the valley at tower 6. The train enters at 11.2 s, visibly slows over the top — the dashboard reads 56 mph up there, upside down — and finishes in 20.8 s at 70 mph top speed. (56 should ring a bell: the loop top stands at 18 m, the exact height of Ride Log twins 9 and 13. Same height, same speed — even upside down.)
The remix · make it yours

Turn the dials — or double them

One loop, your way: two dials, that's it. LOOP_AT = tower number × 20. LOOP_R = anything under your budget. Move it, grow it, shrink it — run after every change.

Two loops: every zone gets a twin with a 2 in its name — LOOP2_AT, on_loop2, angle2 — plus one new rule: the ride is longer than the map now, because loop 1 added ~50 m of rail. So loop 2's trigger is LOOP2_START = LOOP2_AT + LOOP_LEN — its map address, plus every earlier loop's rail. The complete remix, ready to run (loop 2 at tower 14):

# ==========================================================
#  LOOPLINE PARK - COASTER SIMULATOR  (loop edition)
#  THE REMIX: two loops. Same five zones, each with a twin.
# ==========================================================

import pygame
import math

# --- YOUR TRACK -------------------------------------------
# Each number is a hill height in meters, left to right.
# Rule 1: the FIRST number is the lift hill. It must be the tallest.
# Rule 2: change these numbers and rerun. That IS the design job.

track = [50, 48, 42, 33, 22, 11, 2, 0, 8, 18, 26, 30, 26, 18, 9, 3, 0]

SEG_LEN = 20          # each hill tower sits 20 meters from the next

# === LOOP ZONE 1 of 5: the dials ==========================
LOOP_AT = 120.0       # meters along the track (tower 6 = 6 x 20, the valley)
LOOP_R = 8.0          # loop radius in meters
LOOP_LEN = 2 * 3.14159 * LOOP_R      # extra rail the loop adds (~50 m)

LOOP2_AT = 280.0      # MAP meters, just like LOOP_AT (tower 14 = 14 x 20)
LOOP2_R = 8.0
LOOP2_LEN = 2 * 3.14159 * LOOP2_R
LOOP2_START = LOOP2_AT + LOOP_LEN    # THE ADDRESS RULE: the ride reaches it
                                     # late, because loop 1 added rail first

GRAVITY = 9.8
FPS = 60
DT = 1.0 / FPS        # how much time passes in one frame

# --- COLORS (Loopline Park) -------------------------------
NAVY = (27, 41, 81)
YELLOW = (252, 211, 77)
RED = (220, 38, 38)
CREAM = (248, 250, 252)
GREEN = (16, 185, 129)

# --- SETUP ------------------------------------------------
pygame.init()
screen = pygame.display.set_mode((900, 600))
pygame.display.set_caption("Loopline Park - Coaster Simulator")
clock = pygame.time.Clock()
big = pygame.font.SysFont("couriernew", 30, bold=True)
small = pygame.font.SysFont("couriernew", 18)

# --- TURNING A HILL HEIGHT INTO A SCREEN SPOT -------------
tallest = max(track)
step_x = 800 / (len(track) - 1)
scale_y = 400 / tallest

rail_points = []
for i in range(len(track)):
    x = 50 + i * step_x
    y = 550 - track[i] * scale_y
    rail_points.append((x, y))

# === LOOP ZONE 2 of 5: where the circle sits on screen ====
loop_seg = int(LOOP_AT / SEG_LEN)
if loop_seg > len(track) - 2:
    loop_seg = len(track) - 2        # same guard the engine uses
loop_frac = (LOOP_AT - loop_seg * SEG_LEN) / SEG_LEN
loop_base = track[loop_seg] + (track[loop_seg + 1] - track[loop_seg]) * loop_frac
loop_cx = 50 + (LOOP_AT / SEG_LEN) * step_x
loop_cy = 550 - (loop_base + LOOP_R) * scale_y
loop_rpx = LOOP_R * scale_y

loop2_seg = int(LOOP2_AT / SEG_LEN)
if loop2_seg > len(track) - 2:
    loop2_seg = len(track) - 2       # same guard the engine uses
loop2_frac = (LOOP2_AT - loop2_seg * SEG_LEN) / SEG_LEN
loop2_base = track[loop2_seg] + (track[loop2_seg + 1] - track[loop2_seg]) * loop2_frac
loop2_cx = 50 + (LOOP2_AT / SEG_LEN) * step_x
loop2_cy = 550 - (loop2_base + LOOP2_R) * scale_y
loop2_rpx = LOOP2_R * scale_y

# --- RUN THE RIDE -----------------------------------------
top = track[0]
position = 0.0                       # how many meters along the track we are
track_length = (len(track) - 1) * SEG_LEN + LOOP_LEN + LOOP2_LEN   # ZONE 3a: both loops add rail
speed = 2.0
stalled = 0
fell = 0                             # ZONE 3b: the new failure flag

for frame in range(3000):
    pygame.event.pump()              # keeps the window alive

    # === LOOP ZONE 4 of 5: are we on the loop? =============
    # (must run BEFORE the physics - the physics eats height)
    on_loop = (position >= LOOP_AT) and (position < LOOP_AT + LOOP_LEN)
    on_loop2 = (position >= LOOP2_START) and (position < LOOP2_START + LOOP2_LEN)
    angle = 0.0
    angle2 = 0.0
    flat = position
    if position >= LOOP_AT + LOOP_LEN:
        flat = position - LOOP_LEN           # past loop 1: subtract its rail
    if position >= LOOP2_START + LOOP2_LEN:
        flat = position - LOOP_LEN - LOOP2_LEN   # past both: subtract both
    if on_loop:
        flat = LOOP_AT
        angle = (position - LOOP_AT) / LOOP_R
    if on_loop2:
        flat = LOOP2_AT
        angle2 = (position - LOOP2_START) / LOOP2_R

    # WHERE ARE WE? -- find the two towers we are between
    seg = int(flat / SEG_LEN)
    if seg > len(track) - 2:
        seg = len(track) - 2
    frac = (flat - seg * SEG_LEN) / SEG_LEN

    # our height is part way between those two towers
    height = track[seg] + (track[seg + 1] - track[seg]) * frac
    if on_loop:
        height = height + LOOP_R * (1 - math.cos(angle))   # tell height the truth
    if on_loop2:
        height = height + LOOP2_R * (1 - math.cos(angle2))

    # THE PHYSICS: height you have lost becomes speed you have gained
    drop = top - height
    if drop < 0:
        stalled = 1
    else:
        speed = math.sqrt(2 * GRAVITY * drop)
        if speed < 2:
            speed = 2                # the chain lift lets go at 2 m/s

    # === LOOP ZONE 5 of 5: the loop inspector ==============

    if on_loop and angle > 1.57 and angle < 4.71:

    if on_loop2 and angle2 > 1.57 and angle2 < 4.71:
        if speed * speed < GRAVITY * LOOP2_R:
            fell = 1

    # move forward by however fast we are going
    if stalled == 0 and fell == 0:
        position = position + speed * DT

    # --- DRAW -------------------------------------------------
    screen.fill(NAVY)
    pygame.draw.line(screen, GREEN, (50, 550), (850, 550), 3)
    pygame.draw.lines(screen, YELLOW, False, rail_points, 4)

                         (rail_points[i][0], rail_points[i][1]),
                         (rail_points[i][0], 550), 2)

    # the loop (drawn every frame, before the train)
    pygame.draw.circle(screen, YELLOW, (int(loop_cx), int(loop_cy)), int(loop_rpx), 4)
    pygame.draw.circle(screen, YELLOW, (int(loop2_cx), int(loop2_cy)), int(loop2_rpx), 4)

    # the train (rides the circle while on the loop)
    if on_loop:
        tx = loop_cx + loop_rpx * math.sin(angle)
        ty = loop_cy + loop_rpx * math.cos(angle)
    elif on_loop2:
        tx = loop2_cx + loop2_rpx * math.sin(angle2)
        ty = loop2_cy + loop2_rpx * math.cos(angle2)
    else:
        tx = 50 + (flat / SEG_LEN) * step_x

    pygame.draw.rect(screen, RED, (tx - 16, ty - 14, 32, 14), border_radius=4)

Check yourself · five quick ones

Prove you own it

1 · Order. A friend pastes Zone 4 after the four physics lines instead of before. The code is identical — only the location changed. Why does the loop stop working?

The physics eats height. If Zone 4 hasn't told height the truth about the circle yet, the drop line reads a flat-track height, the sqrt line hands back full valley speed, and the train blasts through the loop without ever slowing. In a program, where a line lives is part of what it means.

2 · Dials. You want the loop at tower 10 with radius 6. Which lines change, what are the new numbers — and is it legal?

Exactly two lines: LOOP_AT = 200.0 (10 × 20) and LOOP_R = 6.0. Legal check: tower 10 stands at 26 m, so the budget is (50 − 26) ÷ 2.5 = 9.6 m — and 6 < 9.6. It rides.

3 · The rule. Tower 11 (30 m), radius 9. Banner or ride? Do the arithmetic before you answer.

Banner. Budget: (50 − 30) ÷ 2.5 = 8 m, and you asked for 9. The train lets go partway up the back — TOO SLOW AT THE TOP. One meter over budget is all it takes.

4 · The address rule. In the remix, why isn't loop 2's trigger just LOOP2_AT? Why add LOOP_LEN?

Because the ride is longer than the map. position counts rail travelled, and loop 1 added ~50 m of rail — so everything past it arrives ~50 m of position later than its map address says. Forget the + LOOP_LEN and loop 2 fires 50 m early, in the wrong place. Add a third loop and its trigger owes both earlier loops' rail.

5 · The twins, extended. In the remix, loop 2 stands at tower 14 (9 m), radius 8 — so its top is at 9 + 16 = 25 m. Loop 1's top read 56 mph. What does loop 2's top read, and how do you know without running?

50 mph — because the speed line only ever asks how far below the lift am I? 50 − 25 = 25 m of drop → about 50 mph, right-side up or upside down, loop or hill. If any tower on any track stands at 25 m, it reads 50 too. One rule, the whole park.
